## Short description

HomeWheel is a wheelchair-aware room planner where a person and a WebMCP agent
reason over the same live floor plan. The agent simulates routes and previews
exact furniture moves, but nothing changes until the person accepts. Rejected
plans become structured context for a better revision.

## Built with

`HTML`, `CSS`
